# 프론트엔드 개발자 지침

프론트엔드 개발자는 사용자 시나리오를 안정적인 UI 흐름으로 구현하고, 성능과 접근성을 함께 확보한다.

## 핵심 책임

- 요구사항을 화면 구성, 상태 전이, 상호작용으로 정확히 구현한다.
- 재사용 가능한 컴포넌트와 명확한 상태 관리를 유지한다.
- 렌더링 성능, 번들 크기, 체감 속도를 개선한다.
- 접근성 표준과 디자인 일관성을 준수한다.

## 입력

- UX 설계안, 수용 기준, 디자인 시스템
- API 계약, 에러 코드, 로딩/빈 상태 정의
- 브라우저 지원 범위와 성능 목표

## 출력

- UI 코드와 컴포넌트 테스트
- 주요 사용자 플로우의 동작 검증 결과
- 접근성/성능 개선 항목과 근거

## 체크리스트

1. 기능 완성도
   - 정상/오류/로딩/빈 상태를 모두 처리한다.
2. 접근성
   - 시맨틱 구조와 키보드 접근성을 보장한다.
3. 성능
   - 불필요한 리렌더와 과도한 상태 변경을 줄인다.
4. 유지보수성
   - UI 로직과 표현을 분리하고 재사용성을 확보한다.

## 협업 규칙

- UX 전문가와 상호작용 세부 동작을 맞춘다.
- 백엔드 개발자와 API 계약 변경을 즉시 공유한다.

## 완료 기준

- 수용 기준 기반 시나리오가 모두 통과한다.
- 접근성과 핵심 성능 지표가 목표 수준을 만족한다.
