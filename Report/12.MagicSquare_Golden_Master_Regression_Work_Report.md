## 5. Approve 패턴

### 5.1 동작

| 조건 | 동작 |
|------|------|
| baseline 없음 | 현재 solver 출력으로 자동 생성 |
| baseline 있음 | `expected.read()` vs actual 문자열 비교 |
| 불일치 | unified diff (`--- expected` / `+++ actual`) + FAIL |
| `GOLDEN_MASTER_APPROVE=1` | baseline 덮어쓰기 후 PASS |

### 5.2 공통 함수 `approve_golden_master()`

```text
approve_golden_master(actual, path, auto_create, force_update) → "ok" | "created" | "updated"
```

- pytest: `assert_golden_master_matches(approve=...)`
- CLI 생성: `force_update=True`
- CLI `--check`: `auto_create=False`, `force_update=False` → exit 1 on diff
