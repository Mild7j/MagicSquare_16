### 4.2 orchestration

```
UIBoundary.solve(grid)
  → BoundaryValidator.validate_size()
  → SolvePartialMagicSquare.resolve()
       → find_blank_coords()   # locate
       → find_not_exist_nums() # find
```

## 6. GUI 설치 이슈 (Windows Store Python)

### 6.1 증상 (Git Bash)

```
Defaulting to user installation because normal site-packages is not writeable
ERROR: OSError ... PyQt6\Qt6\qml\QtQuick\Controls\FluentWinUI3\...\png
HINT: Windows Long Path support
```

### 6.2 원인

- **Windows Store Python** 전역 `pip` 사용
- PyQt6-Qt6 wheel 경로가 Windows long path 한도 초과

### 6.3 해결

**프로젝트 `.venv`의 Python/pip 사용:**

```bash
source .venv/Scripts/activate
python -m pip install -e ".[gui]"
```

또는:

```bash
.venv/Scripts/python.exe -m pip install -e ".[gui]"
```
