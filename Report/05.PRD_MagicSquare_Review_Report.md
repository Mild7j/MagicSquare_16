## 4. PRD 본문 핵심 확정 사항

`docs/PRD_MagicSquare.md`에서 구현 전에 고정된 핵심 계약:

| 항목 | 확정 내용 |
|------|-----------|
| 입력 | 4x4 `int[][]`, `0`=빈칸 2개, 값 `0` 또는 `1~16`, 0 제외 중복 금지 |
| 출력 | `int[6]` = `[r1,c1,n1,r2,c2,n2]`, 좌표 1-index |
| Solver | Attempt 1: small→blank1, large→blank2 / Attempt 2: reverse |
| 실패(도메인) | `ERR_UNSOLVABLE` 반환 (예외 throw 아님) |
| Boundary 실패 | `ERR_INVALID_SIZE`, `ERR_INVALID_BLANK_COUNT`, `ERR_OUT_OF_RANGE`, `ERR_DUPLICATE_NON_ZERO` |
| Domain 미호출 | 입력 검증 실패 시 Domain resolver 호출 금지 |
| Magic constant | 34 |
| FR | FR-01~05 (Boundary 검증, Blank, Missing, Validate, Solver+Format) |
| BR | BR-01~13 |
| NFR | Domain 95%+, Boundary 85%+, Project 80%+, Determinism, No side effects, 50ms |

## 6. 발견 이슈 및 개선안

### 6.1 AC / FR (P1-xx)

| ID | 문제 | 개선안 |
|----|------|--------|
| P1-01 | FR-01 성공 경로 AC 없음 | `AC-FR01-06`: TD-01 통과 시 Domain 호출 허용 |
| P1-02 | FR-02 좌표 기대값 없음 | TD-01 기준 `(1,3)`, `(3,4)` 등 AC에 명시 |
| P1-03 | FR-03 누락 숫자 쌍 없음 | TD-01 기준 `(3, 12)` AC 추가 |
| P1-04 | 내부/외부 index 규칙 미분리 | Domain 0-index, Boundary 출력 1-index 정책 AC화 |
| P1-05 | 오류 메시지 exact-match AC 없음 | Track A에 메시지 일치 AC 추가 |
| P1-06 | 출력 계약 검증 FR 부재 | FR-05b 분리 또는 `AC-FR05-05` 추가 |
